Page rule :  PDF page = printed page + 23   (verified on printed 21/69/120/180/242)

PURPOSE — unlike the concept trunks (EM, QM, ...), this trunk is a PROBLEMS
library: one module per book chapter, and the module's problems/problems.md
works EVERY exercise of that chapter (statements transcribed, full stepwise
solutions, code checks). The book prints no solutions; every solution here is
module-authored and machine-verified where the problem admits a check
(identities verified numerically on random inputs, closed forms against
series/quadrature, limiting cases, known special values).

Exercise numbering: the book labels exercises C.S.N (chapter.section.number,
tied to the section they exercise); we keep those labels inside the sequential
### P<n> problem tags the browser parses.

Module shape (trunk convention): README.md, notes.md (compact map of the
chapter results the solutions lean on, with printed-page cites), refs.md
(page-verified, +23 offset), problems/problems.md (ALL exercises: ### P<n>.
Exercise C.S.N — title *(Wilcox 2e §C.S, p.X)*, statement, **Solution.** full
steps), code/<slug>.py + code/test_<slug>.py (numpy/scipy checks; plain-python
test harness printing "All N tests passed.").
