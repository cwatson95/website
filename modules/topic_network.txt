PURPOSE
  A categorized network of physics topics, each a candidate "module" (a self-
  contained unit: notes + worked problems + code/figures). Trunks below map onto
  the shelves already in  books/library/ . This file is the index; modules get
  built out under  modules/<TRUNK>/<ID>_<slug>/  as we go.

HOW TO READ
  Trunks are top-level subjects (MA, CM, EM, QM, RE, ...). Each trunk lists
  modules in rough prerequisite order (top -> down). A module is a leaf you can
  sit down and learn/build in one focused unit.

  This is a NETWORK, not just a tree: the "~" tags are cross-links to related
  modules in OTHER trunks. They are the edges that make physics one subject.
  The deepest edges are collected at the bottom under KEY BRIDGES.

LEGEND
  [XX]        trunk tag
  XX-01       stable module id (use these when cross-referencing / naming files)
  ~YY-nn      cross-link to a related module in another trunk (a network edge)
  shelf:      where the source textbooks live under books/library/
  [adv]       advanced / optional for a first pass
  (->)        ties into your own research code in this repo

 KEY BRIDGES  -- the network backbone (the deepest cross-trunk edges)
================================================================================
  B1  Variational principle:  MA-13 -> CM-17 (Lagrangian) -> CM-21 (Hamilton-
      Jacobi) -> QM-19 (path integral) -> RE-12 (geodesics).  One idea, 4 trunks.
  B2  The continuity equation:  CM-22 (mass) = EM-13/EM-14 (charge) = QM-04
      (probability) = PK-02/SM-06 (phase space).  Same law, different density.
  B3  Angular momentum:  CM-09 -> CM-13 (inertia tensor) -> QM-10/QM-11 (operators
      & spin) -> QM-13 (addition).
  B4  The 1/r potential:  CM-11 (Kepler) -> QM-12 (hydrogen atom) -> RE-14
      (Schwarzschild orbits).  Same force law, three regimes.
  B5  Tensors:  MA-16/MA-17 -> CM-13 (inertia) -> EM-18 (field tensor) -> RE-09..
      RE-13 (curvature & Einstein equations).
  B6  The oscillator:  CM-15 (SHM) -> CM-16 (normal modes) -> QM-09 (quantum SHO)
      -> QF-01 (a field = infinitely many oscillators).
  B7  Poisson bracket -> commutator:  CM-20 -> QM-05.  {A,B} -> (1/i hbar)[A,B].
  B8  Symmetry -> conservation:  MA-18 (groups) -> CM-18 (Noether) -> QF-03 (gauge).
  B9  Fourier / spectral:  MA-09 -> CM-16, EM-15, QM-08 (momentum space), SM, PK.
  B10 Ladder of descriptions:  SM-03 (stat mech) -> SM-06/PK-01 (Boltzmann) ->
      CM-23/PK-02 (fluid).   (-> exactly your KrF kinetics chain)
  B11 Probability -> statistical physics:  ST-05 (expectation) -> ST-12 (Gaussian)
      -> ST-18 (CLT / law of large numbers) -> SM-01 (ensembles) -> SM-03 (partition
      functions).  Why macroscopic averages are sharp; the ST trunk deep-dives MA-19.
