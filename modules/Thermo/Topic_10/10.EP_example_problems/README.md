# 10.EP — Example Problems (Topic 10)

A support module for **Topic 10 (Engines)**: the worked **Examples** from Moran 8e
Ch.5 that exercise the Carnot engine, summarized and **regenerated by code** so every
published answer is verified — plus a module-authored Stirling analysis, since Moran
has no worked Stirling Example (§9.8.4 verified descriptive-only). Part of the
`10.EQ / 10.EP / 10.HP` support set.

## Contents
- `examples.md` — Examples 5.1–5.3 (GIVEN / FIND / ANSWER / METHOD + page) with
  their Quick Quizzes, the explicit no-Stirling-Example note, and Ex S.1.
- `code/examples.py` — each example regenerated from its GIVEN data via the concept
  modules `10.1` (carnot_engine) and `10.2` (stirling_engine).
- `code/test_examples.py` — asserts each result matches the book's answer.
