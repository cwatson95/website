# 8.EP — Example Problems (Topic 8)

A support module for **Topic 8 (Components & Devices)**: the worked **Examples** from
Moran 8e Ch.4/6/10 for the topic's devices, summarized and **regenerated by code** so
every published answer is verified. Part of the `8.EQ / 8.EP / 8.HP` support set
(`modules/Thermo/plan.txt`).

## Contents
- `examples.md` — the 8 Examples (4.5, 4.7, 4.8, 6.14, 10.1–10.4): GIVEN / FIND /
  ANSWER / METHOD + page.
- `code/examples.py` — each example regenerated from its GIVEN data via the canonical
  equations (imported from module `8.EQ`), replicating the book's stepwise rounding.
- `code/test_examples.py` — asserts each result matches the book's answer (including
  the Quick-Quiz follow-ups).
