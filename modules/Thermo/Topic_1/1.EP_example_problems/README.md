# 1.EP — Example Problems (Topic 1)

A support module for **Topic 1 (Foundations)**: the worked **Examples** from Moran
8e Ch.1–2, transcribed and **regenerated by code** so every published answer is
verified. Part of the `1.EQ / 1.EP / 1.HP` support set (`modules/Thermo/plan.txt`).

## Contents
- `examples.md` — the 7 Examples (1.1, 2.1–2.6): GIVEN / FIND / ANSWER / METHOD + page.
- `code/examples.py` — each numerical example regenerated from its GIVEN data via
  the canonical equations (imported from module `1.EQ`) plus two rate helpers
  (`newton_cooling`, `shaft_power`).
- `code/test_examples.py` — asserts each result matches the book's answer.
