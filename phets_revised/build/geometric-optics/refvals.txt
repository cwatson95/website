2.  ray tracing AGREES with the equation, to machine precision
========================================================================
  For every (kind, f, d_o, y_o) and every ray height h, the outgoing
  ray built from the slope law u' = u - h/f must pass through the
  image point the thin-lens equation gives.  Residual = |y_ray(x_img)
  - y_img| / (|y_img| + 1).
  The outgoing ray is at height h + u' s after a signed path length s,
  and the image sits at s = d_i (negative s = the backward extension,
  which is exactly where a virtual image lives).  So the claim is
      h + (u - h/f) d_i  ==  m y_o     for EVERY h.
      worst residual over 1200 configurations: 1.794120407794253e-13
      at ('lens', 80.0, 79.5, 0.0, -13.0)
  (the residual is set by the lever arm: at f = 80, d_o = 79.5 the
   image is 12 720 cm away, so 1e-16 of slope is 1e-12 of height)

  the three PRINCIPAL rays meet at the image point, pairwise:
      worst relative departure over 360 configurations: 1.043454367200147e-15

  a worked case, printed for the suite to pin:
      lens f = 80, object (-170, 27):  image = (151.11111111111111, -24.0)
      h = 27.0                   u' = -0.3375
      h = 0.0                    u' = -0.1588235294117647

      h = 72.5                   u' = -0.8055555555555556
      h = 0.0                    u' = -0.48333333333333334

  the parallel ray really does cross the axis at the BACK focal point:

3.  the lens maker's equation, and PhET's use of it
========================================================================

      1/f = (n-1)(1/R - 1/(-R)) = 2(n-1)/R   =>   f = R / (2(n-1)).

  the surface type; its doc/model.md prints f = R/(2(1-n)), which is

8.  the drawn optic is not the modelled optic (PhET's own note)
========================================================================
  PhET draws its lens with a "hollywooded" sag  a = (D/2)^2 / (2(|R|+100))
  instead of the true sag  |R| - sqrt(R^2 - (D/2)^2).  At its defaults:
      R =  80.0 D =  80.0   drawn half-thickness = 4.444444444444445       true sag = 10.717967697244902
      R =  40.0 D = 120.0   drawn half-thickness = 12.857142857142858      true sag = nan
      R = 120.0 D =  60.0   drawn half-thickness = 2.0454545454545454      true sag = 3.8104996137774947
  Its MIRROR shape uses the true sag  |R| - sqrt(R^2 - (D/2)^2):
      R = 180.0 D =  80.0   sag = 4.5007122521575695
      R = 150.0 D = 120.0   sag = 12.522729151324796
